# Frontend (React)

This folder documents the frontend direction for TrustShield AI.

## Core UX Surfaces

- Claim submission and automated claim visibility dashboard
- Risk score visualization
- Fraud alert interface
- Worker onboarding and verification messaging
- Admin analytics and moderation dashboard
- Demo flow and how-to-use experience
- Futuristic 404 experience

## Frontend Goals

- Responsive UI for desktop and mobile
- Premium motion design and hover interactions
- Graphs and charts backed by API data
- Clear explanation of risk, fraud, and payout decisions
- Product storytelling for architecture, trust, and resilience

## Tech Stack

- React.js
- Tailwind CSS
- Framer Motion
- Recharts
- React Three Fiber
